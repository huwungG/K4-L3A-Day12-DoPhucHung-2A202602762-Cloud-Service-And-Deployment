## Biến môi trường đã set


| Tên biến      | Giá trị                      |
| ------------- | ---------------------------- |
| AGENT_API_KEY | Giá trị từ Railway Dashboard |
| REDIS_URL     | Giá trị từ Railway Redis     |
| PORT          | 8000                         |


## Hướng dẫn deploy

1. Push code lên GitHub repository
2. Kết nối repository với Railway
3. Tạo Redis instance trên Railway
4. Set các biến môi trường trong Railway Dashboard
5. Deploy tự động bắt đầu
